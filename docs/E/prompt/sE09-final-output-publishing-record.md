## Design Notes

- The full provenance chain must be completely visible without any interaction. This is the cross-module audit demonstration — from a KOL session summary in Module C to a LinkedIn post — all steps visible, all sign-offs recorded.
- The "Digital sign-offs are approval stamps, not full Part 11 e-signatures" note is important — it matches the v0.2 PRD clarification in §8.1 and should be visible to any auditor reviewing this record.
- Master Library push at the end of Module E creates the cycle: Module A/B/C/D → Master Library → Module E ideation → Master Library push → next Module E project. Show this circular value as a design note or platform description chip.
